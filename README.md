# Aaryan Shukla Portfolio
Static interactive portfolio for GitHub Pages.

Files:
- index.html
- styles.css
- script.js
- assets/Aaryan_Shukla_Resume.pdf (add your latest resume PDF)

Before publishing, replace `YOUR_EMAIL@example.com` in `index.html`.

Interactions include scroll reveal, dynamic role typewriter, cursor-proximity name scramble, tech marquee, active navigation, experience accordions, project filters, project detail modals, leadership toast feedback, and responsive mobile navigation.
